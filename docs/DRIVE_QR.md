# ファイルを Google ドライブに上げて QR を手帳に貼る

紙に貼れるのは QR まで。実体はドライブに置いておき、手帳の QR をスマホで読めば開ける、
という運用です。

## 連携なしでもできること（設定 0 分）

QR タブは**任意の URL・テキスト**を QR にできます。ドライブの画面で
「リンクをコピー」したものを貼り付ければ、それだけで QR が出せます。
まずはこれで足りるか試してみてください。

```
QR タブ → 内容欄に URL を貼付 → 見出しを入れる → 印刷
```

Wi-Fi 設定・電話番号・地図リンクのプリセットボタンも置いてあります。

## アプリからアップロードする場合

「ファイルを選ぶ → アップロード → リンク取得 → QR 印刷」を 1 ステップにします。
OAuth の初期設定が必要です（一度だけ）。

### 1. ライブラリを入れる

```bash
pip install google-api-python-client google-auth-oauthlib
```

### 2. OAuth クライアントを作る

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作る（既存でも可）
2. **API とサービス → ライブラリ** → 「Google Drive API」を有効化
3. **API とサービス → OAuth 同意画面** → ユーザーの種類は「外部」、
   テストユーザーに自分の Gmail アドレスを追加
   （社内利用なので公開申請は不要。テストユーザーのままで使えます）
4. **API とサービス → 認証情報 → 認証情報を作成 → OAuth クライアント ID**
   → アプリケーションの種類は **デスクトップ アプリ**
5. JSON をダウンロードし、**`credentials.json`** という名前で
   アプリのデータフォルダに置く

データフォルダの場所は `設定` タブの「データ保存先」に表示されています。

| OS | 既定の場所 |
| --- | --- |
| Windows | `%APPDATA%\thermal.memo\credentials.json` |
| macOS | `~/Library/Application Support/thermal.memo/credentials.json` |

### 3. 初回アップロード

`QR` タブ → **ファイルを選んでアップロード…**
→ ブラウザが開くので自分の Google アカウントで許可
→ 以後は `drive_token.json` が使われ、認証は不要になります

取得したリンクが自動で内容欄に入り、ファイル名が見出しに入るので、そのまま印刷できます。

### 要求する権限について

スコープは **`drive.file`** だけです。これは
**このアプリが作成・アップロードしたファイルにしかアクセスできない**権限で、
ドライブの他のファイルは読めません。

## 共有設定の考え方

**既定では共有設定を変更しません。**

- 自分のスマホで自分の Google アカウントにログインしていれば、
  非公開のままでも QR から開けます。**通常はこれで十分です**
- 「リンクを知っている全員に公開」にチェックを入れた場合のみ、
  `anyone with the link` を付与します。リンクを知れば誰でも開けるので、
  **患者情報を含むファイルでは使わないでください**（チェック時に確認ダイアログが出ます）

保存先フォルダを固定したいときは、ドライブでフォルダを開いた URL

```
https://drive.google.com/drive/folders/1AbCdEf...   ← この末尾が ID
```

の ID を `設定` タブの「フォルダID」に入れてください。

## QR の設定

| 項目 | 目安 |
| --- | --- |
| サイズ % | 手帳に貼るなら 50〜70%（80mm 紙で約 36〜50mm 角） |
| 誤り訂正 | 既定 **Q**。サーマル印字は経時で薄れるので L より Q/H が安全 |
| URL も文字で印字 | オン推奨。QR が読めなくなっても手入力で復旧できる |

長い URL は QR が細かくなります。読み取りが厳しいときは
サイズ % を上げるか、Google の短縮 URL などで短くしてください。

## 検証について

生成した QR が実際に読めることは、テストで自動確認しています
（`tests/test_integrations.py`）。プリンタへ送るバイト列を復元した PNG を
OpenCV でデコードし、元の URL と一致することまで見ています。
