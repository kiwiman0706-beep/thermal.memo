# 印刷した控えを Gmail に貯める

印刷のたびに自分宛へメールを送り、Gmail 側のフィルタでラベルを自動付与して管理する運用。
同期フォルダ方式より**検索が強く**、スマホでもそのまま読めます。

> **先に確認を。** 患者情報を含みうる内容を外部のメールサービスへ送ることになります。
> 院内の運用方針・個人情報の取り扱いに照らして問題ないか確認してから有効にしてください。
> 既定はオフです。

## 1. Gmail 側の準備（5 分）

### アプリパスワードを作る

Gmail は通常のパスワードでの SMTP ログインを受け付けません。

1. Google アカウント → セキュリティ → **2 段階認証プロセス**を有効にする（必須）
2. 同じ画面の **アプリ パスワード** で新規作成
3. 表示される 16 桁を控える（この画面を閉じると二度と表示されません）

### 送信先はプラスアドレスにする

宛先を `あなた+memo@gmail.com` のようにしておくと、フィルタ条件が
**件名の文字列に依存せず**確実になります（`+memo` 付きでも同じ受信箱に届きます）。

### フィルタを作る

Gmail の検索窓右の**フィルタアイコン** → 条件に

```
To: あなた+memo@gmail.com
```

（プラスアドレスを使わない場合は `件名: [thermal.memo]`）

→ 「フィルタを作成」→ 次にチェックを入れる:

- [x] **ラベルを付ける** → 新規ラベル `手帳メモ`
- [x] 受信トレイをスキップ（アーカイブする） ← 受信箱を汚したくない場合
- [x] 迷惑メールにしない

## 2. アプリ側の設定

`設定` タブ → **メールで自分宛に控えを送る**

| 項目 | 値 |
| --- | --- |
| 印刷のたびにメールで送る | チェック |
| 送信先 | `あなた+memo@gmail.com` |
| ユーザー名 | `あなた@gmail.com` |
| SMTP / ポート | `smtp.gmail.com` / `465`（SSL） |
| 件名 | `[thermal.memo] {date} {title}` |
| アプリPW | 16 桁を入力 → **保存** |

**テスト送信**で 1 通届けば完了です。

### 件名テンプレート

| 置き換え | 例 |
| --- | --- |
| `{date}` | 2026-09-05 |
| `{time}` | 14:23 |
| `{datetime}` | 2026-09-05 14:23 |
| `{title}` | 本文の 1 行目（QR は見出し、ファイルはファイル名） |
| `{kind}` | text / screenshot / document / qr |

たとえば `[memo] {kind} {date} {title}` にすると、Gmail の検索で
`label:手帳メモ kind` のような絞り込みがしやすくなります。

## 3. アプリパスワードの保管先

平文でファイルに書く経路は用意していません。次の順で探します。

| 順 | 保管先 | 条件 |
| --- | --- | --- |
| 1 | 環境変数 `THERMAL_MEMO_SMTP_PASSWORD` | CI や検証用 |
| 2 | keyring | `pip install keyring` が入っている |
| 3 | Windows DPAPI | Windows。ログイン中のユーザーだけが復号可 |
| 4 | macOS キーチェーン | macOS |
| 5 | （保存しない） | 上記いずれも不可な環境 |

現在どれが使われるかは設定タブに表示されます。Windows / macOS なら追加インストールは不要です。

## 4. 送られるメールの中身

- **本文**: 印刷したテキストそのもの（＋日時・種別・プリンタ）。Gmail の全文検索に乗ります
- **添付**: 実際に印字した 1bit PNG（数 KB）。スクショや QR は添付を見れば内容が分かります
- **ヘッダ**: `X-Thermal-Memo: 1`（Gmail のフィルタからは使えませんが、他のクライアント用）

添付が不要なら「印刷画像を添付」を外してください。

## 5. うまくいかないとき

| 症状 | 対処 |
| --- | --- |
| 認証に失敗する | 通常のパスワードではなくアプリパスワードか確認。2 段階認証が有効か確認 |
| 接続できない | ポート 465（SSL）か 587（STARTTLS）か。院内ネットワークが SMTP を塞いでいないか |
| 印刷は成功するがメールだけ失敗 | 印刷を止めない設計です。ステータスバーに警告が出ます |
| 失敗した印刷も記録したい | 「印刷成功時のみ送る」を外す |

## Gmail 以外を使う場合

SMTP なら何でも使えます。院内メールサーバや Outlook / Fastmail など、
`SMTP` `ポート` `ユーザー名` を変えるだけです。
